 Project Overview (complete)This project involves the design and development of a responsive website for Leeboo Bakes . The organisation currently has limited online presence. The purpose of the website is to increase visibility, provide accurate information about services, and allow users to contact/donate/volunteer online. 
 The website will be built using HTML5, CSS and JavaScript for Part 1, with Part 2 and Part 3 adding interactivity and backend functionality.4. Website Goals and ObjectivesGoals:To create a professional online presence for the organisation.To increase public awareness and community engagement.To make information easily accessible on all devices.Objectives:Design a fully responsive website that works on mobile, tablet and desktop.Provide clear navigation with Home, About, Services, Gallery, Contact pages.
 Increase user inquiries via a functional contact form by 50%.
 Improve SEO visibility with proper meta tags and semantic HTML.Ensure accessibility and fast loading time.
